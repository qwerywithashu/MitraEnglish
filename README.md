# Mitra English (Android)

Offline English learning app. Koi AI ya server nahi.

## APK kaise banega (free, GitHub se)
1. github.com pe free account banao.
2. New repository banao (naam: MitraEnglish).
3. Is folder ki saari files upload karo (`.github` folder bhi).
4. Repository mein **Actions** tab kholo. "Build APK" chalega (3-5 minute).
5. Green tick aane par run kholo, neeche **Artifacts** mein `MitraEnglish-APK` download karo.
6. Zip kholo, `app-debug.apk` phone mein install karo ("Unknown apps" allow karna padega).

App ka content `app/src/main/assets/index.html` mein hai.
